GITHUB PAGES PAR FREE PUBLISH KARNE KA TAREEQA
=============================================
1. Browser mein https://github.com/storecraftstudio/storecraftstudio.github.io kholein.
2. Apne GitHub account mein sign in karein.
3. Repository page par Add file > Upload files par click karein.
4. Is ZIP ko pehle apne computer par Extract All karein. ZIP file khud upload na karein.
5. Extracted folder ke ANDAR ki files aur assets folder select karke GitHub upload area mein drag karein. index.html root par hona chahiye, kisi extra folder ke andar nahi.
6. Neeche Commit changes par click karein. Agar existing files replace karne ka poochay to carefully review karke confirm karein.
7. Repository Settings > Pages par jaayein. Build and deployment mein Deploy from a branch select karein, branch main (ya repository ki default branch), folder /(root), phir Save.
8. Kuch minutes wait karein. Site ka address aam tor par https://storecraftstudio.github.io/ hoga, agar yeh repository aapke control mein hai aur Pages enabled hain.

AGAR REPOSITORY KA ACCESS NA HO:
Apne GitHub account mein nayi repository banayein, jiska naam USERNAME.github.io ho (USERNAME apna exact GitHub username). Extracted files root par upload karein aur Settings > Pages enable karein. Is se free address https://USERNAME.github.io mil sakta hai.
